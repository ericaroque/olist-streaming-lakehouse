Olist Streaming Lakehouse
Data engineering portfolio project using Databricks, Apache Airflow, and Power BI with the Brazilian Olist e-commerce dataset.

Status — In development.
Project scope
- Incremental file ingestion with Databricks Auto Loader.
- Bronze, Silver, and Gold layers using Delta Lake.
- Data transformations and quality rules with PySpark and SQL.
- Dimensional modeling and a Power BI dashboard.
- Job configuration and deployment with Databricks Asset Bundles.
- Pipeline tasks run in Databricks Workflows, with Apache Airflow triggering the jobs and monitoring their execution.
The project uses historical data to simulate new file arrivals. Kafka event replay is planned for a later version.

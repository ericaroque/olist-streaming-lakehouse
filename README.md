Olist Streaming Lakehouse

Data Engineering portfolio project using Databricks and Power BI with the Brazilian Olist e-commerce dataset.

Status: In development.

Planned scope

* Incremental file ingestion with Auto Loader.
* Bronze, Silver and Gold layers using Delta Lake.
* Data transformations and quality rules with PySpark and SQL.
* Dimensional modeling and a Power BI dashboard.
* Deployment with Databricks Bundles.

The project uses historical data and simulates new file arrivals. Kafka event replay is planned for a later version.
